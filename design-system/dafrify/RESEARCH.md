# Research notes — DAFTRIFY rebuild (pre-build)

Written before code. This is the judgment layer.

## What the three favourite references actually do

### Lusion (all-time favourite for motion/UX, not colour)
- Shock is **craft + continuity**, not a palette.
- Long one-page scroll, not full-screen scroll-jacking.
- Motion is **directed**: each transition has a job.
- Performance is part of the craft (real devices).
- Static frames still look designed (art direction first).
- Lesson for us: **do not copy WebGL spectacle**. Copy the discipline: fewer moves, each one legible, continuous surface.

### Yaros
- Portrait-led presence, looping identity, bold role list.
- Conversion form as a real working object.
- Lesson: **human operator is visible**. One desk, one person. Not a faceless SaaS.

### Loaf / tactile craft trend
- Objects feel pick-up-able. Material, weight, press, paper.
- Lesson: **documents as physical artefacts**, not UI cards.

## What award jurors actually score (Hon Tran / Awwwards lens)
1. Art direction with a point of view (kill motion — still strong?)
2. Directed motion (choreography, not library effects)
3. Performance (~60fps on mid hardware)
4. Transitions between sections matter as much as sections
5. Reduced-motion path is real craft

By-Kin / Unseen / Obys pattern: **restraint reads as premium**. Editorial type. Continuous surface. Motion that does not call attention to itself yet makes the page one piece.

## What document-ops brands actually are (not SaaS)
BPO/document ops = people + process + QA + exceptions + outcomes.
Not: dashboards, feature grids, AI product UI, chatbot marketing.
Positioning: **outsourced working desk** that receives messy sets and returns organised, reconciled, source-verified packages. Human judgment on gray areas. Controls and evidence as the product.

## What previous DAFTRIFY builds got wrong (anti-slop self-audit)
- Too many simultaneous systems (shader + sound + scan plane + horizontal pin + loader + flags + telemetry).
- Felt like a **portfolio of techniques**, not one idea.
- Still slipped toward “sections with labels” rhythm.
- Motion sometimes hid weak hierarchy.
- WebGL field risked becoming decoration.

## The one idea for this rebuild
**OPEN CASE.**

The whole site is one open case file on a desk.
You do not visit a marketing page. You open a working file and turn its pages.

Macrostructure name: `OPEN CASE`

## Motion budget (deliberately small)
1. Curtain / page settle on load (optional, skippable, short)
2. Display line mask reveal
3. Specimen redlines draw on enter
4. **One** signature dossier sequence (scroll-scrubbed, 5 states max)
5. Stamp press on verify
6. One reused section settle
Everything else: static composition.

## Forbidden (hard)
- Hero → features → testimonials → CTA
- Three equal feature cards
- Pill soup / tag clouds
- Fake stats, clients, logos, approval rates
- Word “AI” in public copy
- Giant cursor trails
- Motion that fails the “kill animation” test
- Second WebGL/3D engine for decoration
