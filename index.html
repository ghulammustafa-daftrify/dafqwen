How a file moves

Four passes. One pair of eyes. Nothing skipped, nothing assumed.

Send

Send the stack exactly as it exists. No renaming, no sorting, no tidying. A short note on what it is and what it is for helps.

Read

Every file is read by hand, page by page. What the stack contains, and what condition it is in, gets mapped first.

Check

Values are checked back against the source documents you provided. Gaps, mismatches, and unreadable pages go into an exception register.

Return

You get one organized package back. The checked set, the exception register up front, and clean exports of the reconciled tables.
